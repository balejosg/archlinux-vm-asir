🔄 El Giro Pedagógico: ¿Por qué DAM y ASIR necesitan entornos distintos?

En el proyecto base (archlinux-vm), la máquina virtual estaba afinada para Programación en DAM 1: OpenJDK 21, Maven, IntelliJ IDEA en el anfitrión y un agente centrado en explicar excepciones de Java (como NullPointerException) y guiar la lógica algorítmica.

Enfoque Original (DAM 1)
  • Módulo: Programación orientada a objetos.
  • Herramientas: Java, javac, Apache Maven, JUnit.
  • Pregunta típica del alumno: "¿Por qué mi ArrayList se sale de rango?"
  • Rol del agente: Pistas de algoritmos, bucles y diagramas de clases.
Nuevo Enfoque (ASIR Sostenibilidad)
  • Módulos: ISO (Sistemas), PAR (Redes), SRI (Servicios), IAW (Web).
  • Herramientas: Docker, Mosquitto MQTT, PowerTOP, cpupower, Python telemetría.
  • Pregunta típica del alumno: "¿Por qué mi contenedor se reinicia o consume 50W sin tráfico?"
  • Rol del agente: Tutor Socrático de infraestructuras verdes, segmentación de redes, permisos POSIX y cálculo de huella de carbono.

🛠️ Punto de Partida: Cómo reproducirlo desde tu Linux

Host Setup

Solo requieres tres utilidades estándar en tu distribución Linux anfitriona:

# En distribuciones basadas en Arch (CachyOS, Manjaro, EndeavourOS):
sudo pacman -S virtualbox virtualbox-host-modules-arch git github-cli qemu-img

# En Ubuntu / Debian / Linux Mint:
sudo apt update && sudo apt install virtualbox git gh qemu-utils
Opción A: Antigravity CLI

Instalable con paru -S antigravity-cli. Ejecuta agy para iniciar la sesión de asistencia.

Opción B: OpenCode (100% Libre)

Instalable en 1 comando: curl -fsSL https://opencode.ai/install | bash. Ideal para centros educativos sin licencias propietarias.

💬 El Diálogo Técnico: Construcción de la Edición ASIR

Petición Docente Paso 1
PROFESOR

«haz una versión de este proyecto pero para mis alumnos de ASIR. Usarán la máquina para desarrollar proyectos tecnológico relacionados con la sostenibilidad https://github.com/balejosg/archlinux-vm»

🛠️ Decisiones de ingeniería ejecutadas por el Agente:

  • Reemplazo del Toolchain: Se sustituyó el entorno exclusivo de desarrollo Java por un stack de administración de sistemas y redes: Docker, Docker Compose, Mosquitto MQTT, PowerTOP, cpupower y herramientas de diagnóstico de tráfico (nmap, tcpdump, iperf3).
  • Reconfiguración de Puertos NAT: Mapeo de puertos para servicios típicos de ASIR hacia el host: 2222 (SSH), 8080 (Web Nginx), 1883 (Broker MQTT), 3000 (Grafana) y 8086 (InfluxDB).
  • Diseño del Rol "Green SysAdmin": Se reescribió AGENTS.md para que el agente enseñe conceptos de eco-diseño: penalizar bucles activos (*busy-waiting*) que queman vatios inútilmente, incentivar arquitecturas basadas en eventos (MQTT) y orientar el uso de imágenes ligeras en Docker.
  • 3 Proyectos Prácticos de Sostenibilidad: Se crearon ejemplos listos para ejecutar con código real (Smart Campus con telemetría de CO2 y luces, calculadora de huella de carbono digital en Python y gestor de políticas de energía con systemd).
  • Portal Web y Documentación: Creación de la página interactiva para los alumnos en GitHub Pages con estética Green IT y descarga directa del archivo OVA.

🌱 Conclusiones: El rol del docente y la IA en la FP

1. Especificación del Contexto Real

El profesor no pierde el tiempo compilando paquetes o configurando permisos manualmente. Define la visión pedagógica y las limitaciones formativas; el agente ejecuta la infraestructura.

2. Tutoría sin Trampas

Al preconfigurar directrices socráticas en el propio sistema operativo de la VM, los alumnos tienen a su lado un tutor que responde a sus dudas técnicas sin darles la solución copiada, reforzando el aprendizaje autónomo.

3. Sostenibilidad Tangible

La sostenibilidad en informática deja de ser una teoría abstracta: los alumnos pueden ver los Vatios subir en pantalla cuando un contenedor satura la CPU y aprender cómo el buen diseño de redes ahorra energía física.
